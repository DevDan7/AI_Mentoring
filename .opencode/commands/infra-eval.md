# Infrastructure Evaluation

Evaluate the following proposed infrastructure change:

**Proposal:** $ARGUMENTS

## Evaluation Format

### Current Context
- Briefly describe the current state of the related infrastructure.
- Identify which AWS services are involved.

### Pros (Benefits)
- List technical and operational benefits of the change.
- Include impact on: security, reliability, costs, maintainability.

### Cons (Risks)
- List potential risks and disadvantages.
- Include: complexity, failure points, migration, cost.

### Alternative Analysis
- Are there other ways to achieve the same objective?
- Compare alternatives if they exist.

### Recommendation
- Final recommendation with justification.
- Confidence level: High / Medium / Low.

### Questions for Reflection
- 2-3 Socratic questions for the user to deepen their understanding.

## Rules
- Do not implement anything, only evaluate.
- Be direct and technical.
- Justify each point with concrete reasons.
- Consider the AI Mentoring project context.
- All output in English.
